## 2. Scoped Live Staging & Regression Checks

- **Security Headers (`https://vouch-u3u7.onrender.com`):** `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`. Frontend [`next.config.ts`](file:///c:/Users/prakh/OneDrive/Desktop/projects/B2B/frontend/next.config.ts) enforces `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`, and CSP (`frame-ancestors 'none'`, `object-src 'none'`).
- **SQLi / XSS / Error Leakage Probes (`https://vouch-u3u7.onrender.com`):** URL-encoded SQLi probe (`' OR 1=1--`) blocked at edge (`403`); unauthenticated `/api/v1/auth/me/?q=<script>...` returned clean JSON `401` (`RAW_XSS=False`, `LEAK=False`); nonexistent route returned clean `404` HTML (`DEBUG=False`).

  - `VoucherDetailAPIView.patch`: enforces `428` missing `version`/`If-Match` and acquires `select_for_update()` inside `transaction.atomic()` (`200` + `409` verified in Neon PG concurrency test).

  - `apps/notifications/views.py`: `_resolve_authorized_company` strictly rejects cross-tenant `403`, unknown `404`, and malformed/conflicting `400`.
  - `safePurgeTenantData`: preserves isolated `outboxQueue`/`operationLog` on company switch and wipes all DB/Vault/SW state on `forceDestroyAll`.

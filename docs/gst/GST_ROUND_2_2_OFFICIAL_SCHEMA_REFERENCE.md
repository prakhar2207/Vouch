# SriLekh GST — Round 2.2 Official Schema & Offline Utility Specification Reference

**Document Version:** 1.0.0  
**Status:** Authoritative Engineering Reference  
**Applicability:** GSTR-1 & GSTR-3B Return Generation, Pre-Export Payload Validation, and Offline Utility Conformance  
**Primary Authorities:** GST Network (GSTN), Central Board of Indirect Taxes and Customs (CBIC), GST Offline Tool Specifications  

---

## 1. Overview & Statutory Background

The Goods and Services Tax Network (GSTN) mandates strict schema specifications for offline utilities and direct API integrations. GST return files generated by SriLekh must conform to these official specifications so that taxpayers, accountants, and Chartered Accountants can import the files directly into the GST Offline Tool or upload them to the GST Portal without schema rejection.

This document details the exact JSON schema structures, data types, field constraints, enumerated codes, and business validation rules for:
1. **GSTR-1:** Outward Supplies Return (Offline Utility Schema v3.1.2).
2. **GSTR-3B:** Monthly Summary & Tax Payment Return (Offline Utility Schema v1.4).
3. **GSTR-2B:** Inward Supply Auto-Drafted Statement (Reconciliation Report Format).

## 2. GSTR-1 Official Offline Utility Schema (v3.1.2)

### 2.1 Header Structure

| Field Name | Type | Required | Description | Constraints / Validation |
| :--- | :--- | :--- | :--- | :--- |
| `gstin` | String | Yes | Supplier's 15-character GSTIN | `^[0-9]{2}[A-Z]{5}[0-9]{4}[A-Z]{1}[1-9A-Z]{1}Z[0-9A-Z]{1}$` |
| `fp` | String | Yes | Return filing period code | `MMYYYY` (e.g. `"082026"` for August 2026) |
| `version` | String | Yes | Offline schema version | `"GST3.1.2"` |
| `cur_gt` | Number | Yes | Gross turnover in current FY | Decimal, 2 decimal places |
| `gt` | Number | Optional| Gross turnover in preceding FY | Decimal, 2 decimal places |

### 2.2 Table-by-Table Section Specifications

#### Table 4: B2B Invoices (`b2b`)
Supplies to registered persons (including Reverse Charge, Deemed Exports, and SEZ).

```json
{
  "b2b": [
    {
      "ctin": "27AAACT2727Q1ZW",
      "inv": [
        {
          "inum": "INV-2026-001",
          "idt": "15-08-2026",
          "val": 118000.00,
          "pos": "27",
          "rchrg": "N",
          "inv_typ": "R",
          "itms": [
            {
              "num": 1,
              "itm_det": {
                "rt": 18.0,
                "txval": 100000.00,
                "iamt": 0.0,
                "camt": 9000.00,
                "samt": 9000.00,
                "csamt": 0.0
              }
            }
          ]
        }
      ]
    }
  ]
}
```

- **Constraints:**
  - `ctin`: 15-character valid recipient GSTIN.
  - `inum`: 1 to 16 alphanumeric characters, slashes (`/`), and hyphens (`-`).
  - `idt`: String formatted as `DD-MM-YYYY`. Must fall within the return period.
  - `val`: Invoice total value (taxable value + taxes), rounded to 2 decimal places.
  - `pos`: 2-digit state code (`01` to `38`, `96`, `97`, `99`).
  - `rchrg`: `"Y"` or `"N"`.
  - `inv_typ`: `"R"` (Regular), `"DE"` (Deemed Export), `"SEWP"` (SEZ with payment), `"SEWOP"` (SEZ without payment), `"CBW"` (Customs Bonded Warehouse).
  - `rt`: Standard GST rate (`0`, `0.1`, `0.25`, `1.5`, `3`, `5`, `6`, `7.5`, `12`, `18`, `28`).
  - Tax Head Rules: If `pos == supplier_state`, `iamt` must be 0 and `camt == samt`. If `pos != supplier_state`, `camt == 0` and `samt == 0`, and `iamt` must equal calculated integrated tax.

---

#### Table 5: B2C Large Invoices (`b2cl`)
Interstate supplies to unregistered persons with invoice value exceeding statutory threshold.

- **Statutory Threshold (CBIC Notification No. 12/2024 - Central Tax):**
  - Return periods $\le$ July 2024: Invoice value $> ₹2,50,000.00$.
  - Return periods $\ge$ August 2024: Invoice value $> ₹1,00,000.00$.

```json
{
  "b2cl": [
    {
      "pos": "23",
      "inv": [
        {
          "inum": "INV-2026-B2CL-01",
          "idt": "20-08-2026",
          "val": 150000.00,
          "inv_typ": "R",
          "itms": [
            {
              "num": 1,
              "itm_det": {
                "rt": 18.0,
                "txval": 127118.64,
                "iamt": 22881.36,
                "csamt": 0.0
              }
            }
          ]
        }
      ]
    }
  ]
}
```

- **Constraints:**
  - `pos != supplier_state` (Mandatory interstate check).
  - Recipient is unregistered (`URP` or blank GSTIN).
  - Only `iamt` and `csamt` are permitted; `camt` and `samt` are prohibited.

Exports of goods or services.

```json
{

    {

      "inv": [
        {

          "sbnum": "SB-88219",
          "sbdt": "08-08-2026",
          "itms": [
            {
              "num": 1,
              "itm_det": {
                "rt": 0.0,
                "txval": 500000.00,
                "iamt": 0.0,
                "csamt": 0.0
              }
            }
          ]
        }
      ]
    }
  ]
}
```

- **Constraints:**
  - `exp_typ`: `"WPAY"` (With payment of tax) or `"WOPAY"` (Without payment of tax under LUT/Bond).
  - `sbnum` & `sbdt`: Optional shipping bill number and date.

#### Table 7: B2C Small Supplies (`b2cs`)
All other supplies to unregistered persons (all intrastate supplies, plus interstate supplies $\le$ threshold).

```json
{
  "b2cs": [
    {
      "sply_ty": "INTRA",
      "pos": "27",
      "typ": "OE",
      "rt": 18.0,
      "txval": 50000.00,
      "iamt": 0.0,
      "camt": 4500.00,
      "samt": 4500.00,
      "csamt": 0.0
    }
  ]
}
```

- **Constraints:**
  - Net of debit/credit notes for small unregistered supplies.
  - Grouped by `(sply_ty, pos, rt)`.

## 3. GSTR-3B Official Offline Utility Schema (v1.4)

### 3.1 Root & Section Architecture

```json
{
  "gstin": "27AAACA1234A1Z5",
  "ret_period": "082026",
  "filing_typ": "GSTR3B",
  "sup_details": {
    "osup_det": {
      "txval": 100000.00,
      "iamt": 0.00,
      "camt": 9000.00,
      "samt": 9000.00,
      "csamt": 0.00
    },
    "osup_zero": {
      "txval": 50000.00,
      "iamt": 0.00,
      "csamt": 0.00
    },
    "osup_nil_exmp": {
      "txval": 10000.00
    },
    "isup_rev": {
      "txval": 20000.00,
      "iamt": 3600.00,
      "camt": 0.00,
      "samt": 0.00,
      "csamt": 0.00
    },
    "osup_nongst": {
      "txval": 0.00
    }
  },
  "inter_sup": {
    "unreg_details": [
      {
        "pos": "23",
        "txval": 150000.00,
        "iamt": 27000.00
      }
    ],
    "comp_details": [],
    "uin_details": []
  },
  "itc_elg": {
    "itc_avl": {
      "import_goods": { "iamt": 0.00, "csamt": 0.00 },
      "import_services": { "iamt": 0.00, "csamt": 0.00 },
      "isup_rev": { "iamt": 3600.00, "camt": 0.00, "samt": 0.00, "csamt": 0.00 },
      "isd": { "iamt": 0.00, "camt": 0.00, "samt": 0.00, "csamt": 0.00 },
      "all_other": { "txval": 80000.00, "iamt": 0.00, "camt": 7200.00, "samt": 7200.00, "csamt": 0.00 }
    },
    "itc_rev": {
      "rule42_43": { "iamt": 0.00, "camt": 0.00, "samt": 0.00, "csamt": 0.00 },
      "others": { "iamt": 0.00, "camt": 0.00, "samt": 0.00, "csamt": 0.00 }
    },
    "itc_net": {
      "iamt": 3600.00,
      "camt": 7200.00,
      "samt": 7200.00,
      "csamt": 0.00
    },
    "itc_inelg": {
      "as_per_sec_17_5": { "iamt": 0.00, "camt": 0.00, "samt": 0.00, "csamt": 0.00 },
      "others": { "iamt": 0.00, "camt": 0.00, "samt": 0.00, "csamt": 0.00 }
    }
  },
  "inward_sup": {
    "isup_details": [
      {
        "ty": "GST",
        "inter": 0.00,
        "intra": 15000.00
      },
      {
        "ty": "NON_GST",
        "inter": 0.00,
        "intra": 0.00
      }
    ]
  }
}
```

### 3.2 Key Invariants Enforced in Schema
1. **Reverse Charge Invariant (Section 49(4)):** `sup_details.isup_rev` captures liability payable on reverse charge. It is strictly excluded from output tax set-off; the taxpayer must discharge it in cash.
2. **Net ITC Mathematical Consistency:** `itc_elg.itc_net` must strictly equal `itc_avl` minus `itc_rev` for each tax head.
3. **Table 3.2 Consistency:** Every interstate supply reported in Table 3.2 must be a subset of the outward supplies reported in Table 3.1.

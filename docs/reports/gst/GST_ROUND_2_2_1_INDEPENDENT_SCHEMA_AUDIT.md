## 1. Executive Summary & Objective

In accordance with Round 2.2.1 directives, an independent, evidence-driven compliance and schema conformance audit was conducted on SriLekh's GST return generation, statutory rate validation, and export engine.

### Three Critical Focus Areas:
1. **Official GSTR-1 Schema Conformance:**
   - Independent verification against the official **GSTN Offline Tool Schema v3.1.2**.
   - Verified that Table 5 (B2CL) groups multiple large invoices under each Place of Supply (`pos`) with `inv_typ: "R"`.
   - Remediated Table 9B CDNUR: transformed structure from nested objects to an official **flat list of note objects** (`typ: "B2CL" | "EXPWP" | "EXPWOP"`).
   - Enforced statutory netting invariant: unregistered small credit/debit notes (B2CS) are **strictly excluded from Table 9B CDNUR** and netted directly into Table 7 (B2CS) turnover and taxes.
   - Enforced Table 8 Nil supplies 4-way statutory breakdown: `INTRAB2B`, `INTRAB2C`, `INTERB2B`, and `INTERB2C`.
   - Verified presence of top-level amendment arrays (`b2ba`, `b2cla`, `b2csa`, `cdnra`, `cdnura`, `expa`, `ata`, `txpda`).

2. **GSTR-3B Compatibility Truth & Product Labels:**
   - Audited the exact nature of the `GST3B1.4` JSON payload.
   - **Finding:** The GST Portal web GUI (`gst.gov.in`) **does NOT accept direct `.json` upload for GSTR-3B** (it only supports manual box entry or Excel macro utility `GSTR3B_Excel_Utility.xlsm`).
   - The JSON format generated by SriLekh adheres to the official **GSTN GSP/ASP Return Filing API Specification (v1.4)** for automated electronic return filing.
   - Clarified all UI labels and export metadata:
     - GSTR-3B JSON is classified as `"GSTN_API_RETURN_PAYLOAD"` (`portal_uploadable: False`).
     - GSTR-3B Review Report is classified as `"STATUTORY_PORTAL_ENTRY_GUIDE"` (`portal_uploadable: False`), providing box-by-box guidance for Table 3.1, 3.2, 4, 5.1.
     - GSTR-1 JSON remains classified as `"OFFICIAL_PORTAL_OFFLINE_TOOL_JSON"` (`portal_uploadable: True`).

3. **Effective-Dated Statutory GST Rate Reference Schedule & Validation:**
   - Replaced fragile static tax rate whitelists (`{0.0, 5.0, 12.0, 18.0, 28.0}`) with an authoritative, effective-dated statutory rate schedule service: [`apps/gst/services/rate_reference_service.py`](file:///c:/Users/prakh/OneDrive/Desktop/projects/B2B/apps/gst/services/rate_reference_service.py).
   - Incorporated CBIC statutory notifications:
     - Notification No. 1/2017-Central Tax (Rate) & 11/2017-Central Tax (Rate) (Goods and Services basic tariff).
     - Notification No. 2/2017-Central Tax (Rate) & 12/2017-Central Tax (Rate) (Goods and Services unconditional exemptions).
     - Notification No. 46/2017-Central Tax (Rate) (Restaurants rate change from 18% with ITC to 5% without ITC w.e.f. 15-Nov-2017).
     - Notification No. 1/2018-Central Tax (Rate) (Rough diamonds 0.25% w.e.f. 25-Jan-2018).
     - Notification No. 12/2019-Central Tax (Rate) (Electric vehicles rate reduction from 12% to 5% w.e.f. 01-Aug-2019).
     - Notification No. 6/2022-Central Tax (Rate) (Pre-packaged and labeled dairy/paneer brought into 5% bracket w.e.f. 18-Jul-2022).
     - Notification No. 40/2017-Central Tax (Rate) & 41/2017-Integrated Tax (Rate) (Merchant exports 0.1%).
     - Goods and Services Tax (Compensation to States) Act 2017 (Compensation Cess, e.g. 22% on luxury motor vehicles >1500cc).
   - Integrated with [`GSTPayloadValidator`](file:///c:/Users/prakh/OneDrive/Desktop/projects/B2B/apps/gst/services/payload_validator.py) to flag `GST_STATUTORY_RATE_MISMATCH` (ERROR with CBIC notification citation) and `GST_RATE_REVIEW_REQUIRED` (WARNING for ambiguous/unrecognized HSN codes).

## 2. Official Schema Specifications & Standards

| Return Type | Export Format | Schema Standard / Specification | Target Consumer | Portal GUI Uploadable |
|:---|:---|:---|:---|:---:|
| **GSTR-1** | JSON | GSTN Offline Tool Schema v3.1.2 | GST Portal (`gst.gov.in`) Returns Offline Utility / Direct JSON Upload | **YES** |
| **GSTR-1** | REVIEW_REPORT | Statutory Audit & Summary Report | Accountants, Internal Auditors, CAs | NO (Audit Only) |
| **GSTR-3B** | JSON | GSTN GSP/ASP API Return Specification v1.4 | Automated GSP / ASP API Submission (`POST /returns/gstr3b`) | **NO** (API Only) |
| **GSTR-3B** | REVIEW_REPORT | Statutory Table-by-Table Portal Entry Guide | Manual Entry on GST Portal Web Form (Boxes 3.1, 3.2, 4, 5.1) | NO (Guide) |
| **GSTR-2B** | RECON_REPORT | SriLekh 11-Category ITC Reconciliation Report | Purchase Register vs Inward 2B Ledger | NO (Internal) |

### Schema Checksums & Structural Specifications:
- **GSTR-1 Schema Checksum (v3.1.2 offline utility):**
  - Section Keys: `gstin`, `fp`, `version` (`"GST3.1.2"`), `cur_gt`, `b2b`, `b2ba`, `b2cl`, `b2cla`, `b2cs`, `b2csa`, `cdnr`, `cdnra`, `cdnur`, `cdnura`, `exp`, `expa`, `nil`, `at`, `ata`, `txpd`, `txpda`, `hsn`, `doc_issue`.
  - Date format: `DD-MM-YYYY` (e.g., `15-08-2024`).
  - Invoice length: 1 to 16 alphanumeric characters, slashes (`/`), or hyphens (`-`).
  - B2CL threshold: `> ₹2,50,000` (prior to 01-Aug-2024); `> ₹1,00,000` (from 01-Aug-2024 onwards, per Notif No. 12/2024-CT).
- **GSTR-3B API Specification Checksum (v1.4):**
  - Root Keys: `gstin`, `ret_period`, `filing_typ` (`"GSTR3B"`), `sup_details`, `inter_sup`, `itc_elg`, `inward_sup`.
  - Section 49(4) Rule: Reverse charge liability in `sup_details.isup_rev` is 100% cash payable, isolated from `itc_elg`.
